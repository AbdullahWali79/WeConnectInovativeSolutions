We Connect Innovative Solutions is positioned as an international AI automation and software delivery company. The primary commercial focus is n8n, Make.com, custom workflow automation and AI integrations using ChatGPT/OpenAI, Claude and Gemini.

## Canonical domain

Production must define:

```env
NEXT_PUBLIC_SITE_URL=https://weconnectinnovativesolutions.com
```

Use the exact live preferred domain, including `www` only if the deployed canonical domain uses it. Redirect every alternate hostname and HTTP URL to that one HTTPS hostname.

## Blogging rules

1. Publish genuinely useful English articles for decision-makers, not keyword-stuffed posts.
2. Select one clear informational query per article. Examples: `n8n vs Make.com`, `how to automate lead routing`, or `AI agent use cases for customer support`.
3. Link naturally to one relevant service page and to at least one related blog post.
4. Use original diagrams, workflow screenshots, templates, benchmarks or project lessons whenever possible.
5. Add an accurate SEO title, meta description and short excerpt in the blog admin.
6. Keep claims specific and verifiable. Do not invent clients, statistics, reviews or case-study results.
7. Update older posts when tools, interfaces or pricing change.

## Evidence and conversion requirements

Before aggressive link building, add real automation portfolio entries. Each case study should state the initial process, technology used, integrations, delivery constraints and measured outcome. Obtain client permission before publishing names, logos or private metrics.

Every commercial page should retain one primary conversion action leading to the contact form. Track successful contact submissions as a conversion in the analytics platform selected by the business.

## Launch checklist

- Confirm the production canonical domain and set `NEXT_PUBLIC_SITE_URL`.
- Verify both `robots.txt` and `sitemap.xml` on production.
- Create Google Search Console and Bing Webmaster Tools properties.
- Submit `/sitemap.xml` to both platforms.
- Request indexing for the homepage, services hub and seven automation pages.
- Add analytics and contact-form conversion tracking with the required consent handling.
- Confirm redirects enforce one HTTPS hostname.
- Test Open Graph previews and structured data after deployment.
- Record a baseline of impressions, clicks, leads and ranking queries before monthly work begins.

## Reporting

Report business outcomes monthly: qualified enquiries, booked calls and attributed opportunities. Search impressions, clicks, click-through rate, indexed pages, backlinks and target-query movement are supporting metrics—not the final goal.
