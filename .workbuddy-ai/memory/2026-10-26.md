## Redesigned Accounts Manager locked/unlock screen

**File:** `components/admin/accounts-manager/accounts-manager.tsx`

Replaced the plain locked-state card with a decorated screen matching the admin portal theme.

### What changed
- Locked state is now a full block (early return with a `handleUnlock` helper) instead of a one-liner ternary return.
- Added `unlockError` state — replaced the browser `alert('Incorrect password')` with an inline, animated error banner (`role="alert"`, `aria-live="polite"`).
- Card design: navy `bg-primary` header band (matches the admin sidebar, which is `bg-primary` = `--wc-primary: #00216e`), glassmorphic lock badge with gold `--wc-secondary-container` icon, gold gradient accent line, ambient radial glows behind the card.
- Input: `wc-input` with a leading key icon and a trailing visibility toggle icon, `autoFocus`, `aria-invalid`.
- Button: navy with hover lift, lock_open + arrow_forward icons, arrow slides on hover.
- Added decorative feature chips row (Fees / Accounts / Products) below the card.
- Password remains `Abdullah123@` (hardcoded in-component, unchanged behavior).

### Theme conventions learned (project-wide)
- Theme is CSS-variable driven in `app/globals.css`; Tailwind maps them in `tailwind.config.cjs` (e.g. `bg-primary` → `var(--wc-primary)`).
- `wc-card`, `wc-input`, `wc-label` are component classes in `app/globals.css` — prefer these over hand-rolled styling.
- Admin sidebar uses `bg-primary` + `text-blue-100` + `white/10` borders + `white/15` active pill.
- Icons: Material Symbols via `<Icon name="..." />` from `components/icon.tsx`.
- Note: arbitrary opacity like `/8` is NOT a default Tailwind step — use `/10`, `/25`, etc.
